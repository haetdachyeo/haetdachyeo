## 共通アカウント規則

| 項目 | 値 |
| --- | --- |
| アカウント構成 | メールアドレスとパスワードの組み合わせ |
| メールアドレス前処理 | 入力値の両端の空白除去後、検証・アカウント表現に使用 |
| メールアドレス長 | 両端の空白除去後にUnicodeコードポイント基準1～255個、メールアドレス形式も同時に満たす必要があるため、有効なメールアドレスは最小3個 |
| メールアドレス形式 | 空白なし、`@`が正確に1個、空でないローカル部・ドメイン部による`local@domain`形式 |
| メールアドレス比較 | 一意性・ログイン一致ともに大文字・小文字を区別しない |
| メールアドレス重複 | 大文字・小文字のみ相違、または両端の空白除去後に同一なら重複 |
| メールアドレス表示 | 登録時に両端の空白のみ除去した表現を維持、大文字・小文字の任意変更禁止 |
| パスワード前処理 | 入力した正確な値を使用、両端の空白除去・その他の正規化禁止 |
| パスワード文字 | 空白を含むすべてのUnicode文字を許可 |
| パスワード長 | Unicodeコードポイント基準1～255個 |
| パスワード比較 | 登録時の入力値と文字単位で正確に一致 |
