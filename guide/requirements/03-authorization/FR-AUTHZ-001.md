# `FR-AUTHZ-001` 소유권 및 권한 제한

[한국어](FR-AUTHZ-001.md) | [English](FR-AUTHZ-001.en.md) | [日本語](FR-AUTHZ-001.ja.md)

← 돌아가기: [소유권 및 권한 요구사항](../03-authorization.md)

| 항목 | 값 |
| --- | --- |
| 입력 | 포스트 작성, 기존 공개 포스트 수정·영구 삭제 시도, 현재 사용자 식별 상태 |
| 출력·상태 | 역할·포스트 소유권에 따라 허용된 동작만 적용 |
| 검증 | 소유권은 작성 회원에게 귀속 |
| 권한 | 회원 전용 동작은 로그인 필요. 기존 공개 포스트 수정·영구 삭제는 작성자 본인만 허용 |
| 실패·거부 | 무권한 시도는 대상 내용·공개 가용성·소유권을 변경하지 않음 |

| AC ID | 조건 | 기대 결과 |
| --- | --- | --- |
| `AC-AUTHZ-001-01` | 비로그인 사용자 | 포스트 작성과 기존 공개 포스트 수정·영구 삭제 불가 |
| `AC-AUTHZ-001-02` | 회원이 타 회원의 기존 공개 포스트 수정·영구 삭제 시도 | 수정·영구 삭제 불가, 대상 내용·공개 가용성·소유권 불변 |
| `AC-AUTHZ-001-04` | 권한 없는 시도 | 대상 내용·공개 가용성·소유권 불변 |
