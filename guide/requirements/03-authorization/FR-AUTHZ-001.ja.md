# `FR-AUTHZ-001` 所有権および権限制限

[한국어](FR-AUTHZ-001.md) | [English](FR-AUTHZ-001.en.md) | [日本語](FR-AUTHZ-001.ja.md)

← 戻る: [認可要件](../03-authorization.ja.md)

| 項目 | 値 |
| --- | --- |
| 入力 | ポスト作成、既存公開ポストの変更・完全削除の試行、現在のユーザー識別状態 |
| 出力・状態 | 役割・ポスト所有権に応じて許可された操作のみ適用 |
| 検証 | 所有権は作成会員に帰属 |
| 権限 | 会員専用操作にはログインが必要。既存公開ポストの変更・完全削除は作成者本人のみ許可 |
| 失敗・拒否 | 権限のない試行は対象の内容・公開可用性・所有権を変更しない |

| AC ID | 条件 | 期待結果 |
| --- | --- | --- |
| `AC-AUTHZ-001-01` | 未ログインユーザー | ポスト作成および既存公開ポストの変更・完全削除不可 |
| `AC-AUTHZ-001-02` | 会員が他の会員の既存公開ポストの変更・完全削除を試行 | 変更・完全削除不可、対象の内容・公開可用性・所有権は不変 |
| `AC-AUTHZ-001-04` | 権限のない試行 | 対象の内容・公開可用性・所有権は不変 |
