## 공통 계정 규칙

| 항목 | 값 |
| --- | --- |
| 계정 구성 | 이메일과 비밀번호의 조합 |
| 이메일 전처리 | 입력값 양 끝 공백 제거 후 검증·계정 표현으로 사용 |
| 이메일 길이 | 양 끝 공백 제거 후 유니코드 코드 포인트 기준 1~255개, 이메일 형식도 함께 충족 필수이므로 유효 이메일은 최소 3개 |
| 이메일 형식 | 공백 없음, `@` 정확히 1개, 비어 있지 않은 로컬·도메인의 `local@domain` 형식 |
| 이메일 비교 | 고유성·로그인 일치 모두 대소문자 미구분 |
| 이메일 중복 | 대소문자만 다르거나 양 끝 공백 제거 후 같으면 중복 |
| 이메일 표시 | 가입 시 양 끝 공백만 제거한 표현 유지, 대소문자 임의 변경 금지 |
| 비밀번호 전처리 | 입력한 정확한 값 사용, 양 끝 공백 제거·기타 정규화 금지 |
| 비밀번호 문자 | 공백을 포함한 모든 유니코드 문자 허용 |
| 비밀번호 길이 | 유니코드 코드 포인트 기준 1~255개 |
| 비밀번호 비교 | 가입 시 입력값과 문자 단위로 정확히 일치 |
