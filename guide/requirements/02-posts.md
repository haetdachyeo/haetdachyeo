## 공통 포스트 규칙

| 항목 | 값 |
| --- | --- |
| 제목 값 | 입력값 양 끝 공백 제거 후 사용 |
| 제목 검증 | 필수, 양 끝 공백 제거 후 유니코드 코드 포인트 기준 1~255개 |
| 본문 값 | 입력값 양 끝 공백 제거 후 사용 |
| 본문 검증 | 필수, 양 끝 공백 제거 후 유니코드 코드 포인트 기준 1~100,000개 |
| 검증 실패 | 새 포스트 생성 금지, 기존 포스트 값 변경 금지 |
