## 共通ポスト規則

| 項目 | 値 |
| --- | --- |
| タイトル値 | 入力値の両端の空白除去後に使用 |
| タイトル検証 | 必須、両端の空白除去後にUnicodeコードポイント基準1～255個 |
| 本文値 | 入力値の両端の空白除去後に使用 |
| 本文検証 | 必須、両端の空白除去後にUnicodeコードポイント基準1～100,000個 |
| 検証失敗 | 新規ポスト作成禁止、既存ポスト値の変更禁止 |
