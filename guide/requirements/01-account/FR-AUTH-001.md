# `FR-AUTH-001` 회원가입

[한국어](FR-AUTH-001.md) | [English](FR-AUTH-001.en.md) | [日本語](FR-AUTH-001.ja.md)

← 돌아가기: [계정 요구사항](../01-account.md)

| 항목 | 값 |
| --- | --- |
| 입력 | 이메일, 비밀번호 |
| 출력·상태 | 고유 회원 계정 정확히 1개 생성, 이후 해당 이메일·비밀번호로 로그인 가능 |
| 검증 | 공통 계정 규칙 충족, 이메일은 기존 회원 이메일과 대소문자 미구분 고유 |
| 권한 | 로그인하지 않은 방문자 |
| 실패·거부 | 입력 무효·이메일 중복 시 계정 미생성. 오류 표현은 Stage 08에서 결정 |

| AC ID | 조건 | 기대 결과 |
| --- | --- | --- |
| `AC-AUTH-001-01` | 미사용 유효 이메일, 유니코드 코드 포인트 1~255개의 비밀번호 | 회원 계정 정확히 1개 생성 |
| `AC-AUTH-001-02` | 가입 이메일의 대소문자만 변경 또는 양 끝 공백 추가 | 중복 거부, 새 계정 미생성 |
| `AC-AUTH-001-03` | 양 끝 공백 제거 후 이메일이 정확히 3개·255개 코드 포인트이고 형식 충족 / 0개·256개이거나 1~255개여도 `local@domain` 형식 불충족 | 전자는 가입 가능 / 후자는 가입 불가 |
| `AC-AUTH-001-04` | 비밀번호 0개·256개 / 정확히 1개·255개 코드 포인트, 나머지 공통 계정 규칙 충족 | 전자는 가입 불가 / 후자는 가입 가능 |
| `AC-AUTH-001-05` | 길이 조건 충족, 공백·유니코드 문자 포함 비밀번호 | 입력값 변경 없이 가입에 사용 가능 |
