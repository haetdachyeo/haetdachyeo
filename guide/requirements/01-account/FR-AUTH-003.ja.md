# `FR-AUTH-003` ログアウト

[한국어](FR-AUTH-003.md) | [English](FR-AUTH-003.en.md) | [日本語](FR-AUTH-003.ja.md)

← 戻る: [アカウント要件](../01-account.ja.md)

| 項目 | 値 |
| --- | --- |
| 入力 | 現在ログイン中の会員のログアウト要求 |
| 出力・状態 | 当該利用状態で現在の会員識別を終了 |
| 検証 | 現在ログイン中の会員 |
| 権限 | ログインした会員のみ許可 |
| 失敗・拒否 | 未ログイン状態では禁止 |

| AC ID | 条件 | 期待結果 |
| --- | --- | --- |
| `AC-AUTH-003-01` | ログイン会員がログアウト | 以後同じ利用状態で会員専用操作不可 |
| `AC-AUTH-003-02` | 一人の会員のログアウト | 他の会員のログイン状態・データに影響なし |
