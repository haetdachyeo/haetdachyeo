# `FR-AUTH-002` 로그인

[한국어](FR-AUTH-002.md) | [English](FR-AUTH-002.en.md) | [日本語](FR-AUTH-002.ja.md)

← 돌아가기: [계정 요구사항](../01-account.md)

| 항목 | 값 |
| --- | --- |
| 입력 | 이메일, 비밀번호 |
| 출력·상태 | 해당 회원을 현재 로그인 회원으로 식별, 회원 전용 동작 가능 |
| 검증 | 이메일 양 끝 공백 제거·대소문자 미구분 일치, 비밀번호 무전처리·무정규화 정확히 일치 |
| 권한 | 로그인하지 않은 방문자 |
| 실패·거부 | 계정 없음·비밀번호 불일치 시 로그인 상태 미생성. 오류 표현은 Stage 08에서 결정 |

| AC ID | 조건 | 기대 결과 |
| --- | --- | --- |
| `AC-AUTH-002-01` | 가입 이메일의 대소문자 변경 또는 양 끝 공백 추가, 정확한 비밀번호 | 같은 회원으로 로그인 |
| `AC-AUTH-002-02` | 가입 비밀번호의 앞뒤 공백 제거·추가 등 한 문자라도 변경 | 로그인 불가 |
| `AC-AUTH-002-03` | 미가입 이메일 또는 잘못된 비밀번호 | 회원 전용 동작 가능한 로그인 상태 미생성 |
