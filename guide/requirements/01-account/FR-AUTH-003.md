# `FR-AUTH-003` 로그아웃

[한국어](FR-AUTH-003.md) | [English](FR-AUTH-003.en.md) | [日本語](FR-AUTH-003.ja.md)

← 돌아가기: [계정 요구사항](../01-account.md)

| 항목 | 값 |
| --- | --- |
| 입력 | 현재 로그인 회원의 로그아웃 요청 |
| 출력·상태 | 해당 이용 상태에서 현재 회원 식별 종료 |
| 검증 | 현재 로그인 회원 |
| 권한 | 로그인한 회원만 허용 |
| 실패·거부 | 비로그인 상태에서는 금지 |

| AC ID | 조건 | 기대 결과 |
| --- | --- | --- |
| `AC-AUTH-003-01` | 로그인 회원이 로그아웃 | 이후 같은 이용 상태에서 회원 전용 동작 불가 |
| `AC-AUTH-003-02` | 한 회원의 로그아웃 | 다른 회원의 로그인 상태·데이터에 영향 없음 |
