# `FR-AUTH-001` 会員登録

[한국어](FR-AUTH-001.md) | [English](FR-AUTH-001.en.md) | [日本語](FR-AUTH-001.ja.md)

← 戻る: [アカウント要件](../01-account.ja.md)

| 項目 | 値 |
| --- | --- |
| 入力 | メールアドレス、パスワード |
| 出力・状態 | 一意の会員アカウントを正確に1個作成、以後そのメールアドレス・パスワードでログイン可能 |
| 検証 | 共通アカウント規則を満たす、メールアドレスは既存会員のメールアドレスに対して大文字・小文字を区別せず一意 |
| 権限 | ログインしていない訪問者 |
| 失敗・拒否 | 入力無効・メールアドレス重複時はアカウント未作成。エラー表現はStage 08で決定 |

| AC ID | 条件 | 期待結果 |
| --- | --- | --- |
| `AC-AUTH-001-01` | 未使用の有効なメールアドレス、Unicodeコードポイント1～255個のパスワード | 会員アカウントを正確に1個作成 |
| `AC-AUTH-001-02` | 登録メールアドレスの大文字・小文字のみ変更、または両端に空白追加 | 重複拒否、新規アカウント未作成 |
| `AC-AUTH-001-03` | 両端の空白除去後、メールアドレスが正確に3個・255個のコードポイントで形式適合 / 0個・256個、または1～255個でも`local@domain`形式に不適合 | 前者は登録可能 / 後者は登録不可 |
| `AC-AUTH-001-04` | パスワード0個・256個 / 正確に1個・255個のコードポイントで、その他の共通アカウント規則を満たす | 前者は登録不可 / 後者は登録可能 |
| `AC-AUTH-001-05` | 長さ条件を満たし、空白・Unicode文字を含むパスワード | 入力値を変更せず登録に使用可能 |
