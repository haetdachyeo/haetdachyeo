# `FR-AUTH-002` ログイン

[한국어](FR-AUTH-002.md) | [English](FR-AUTH-002.en.md) | [日本語](FR-AUTH-002.ja.md)

← 戻る: [アカウント要件](../01-account.ja.md)

| 項目 | 値 |
| --- | --- |
| 入力 | メールアドレス、パスワード |
| 出力・状態 | 該当会員を現在ログイン中の会員として識別、会員専用操作が可能 |
| 検証 | メールアドレスは両端の空白除去・大文字・小文字を区別せず一致、パスワードは前処理・正規化なしで正確に一致 |
| 権限 | ログインしていない訪問者 |
| 失敗・拒否 | アカウントなし・パスワード不一致時はログイン状態未作成。エラー表現はStage 08で決定 |

| AC ID | 条件 | 期待結果 |
| --- | --- | --- |
| `AC-AUTH-002-01` | 登録メールアドレスの大文字・小文字変更または両端に空白追加、正確なパスワード | 同じ会員としてログイン |
| `AC-AUTH-002-02` | 登録パスワードの前後の空白除去・追加など一文字でも変更 | ログイン不可 |
| `AC-AUTH-002-03` | 未登録メールアドレスまたは誤ったパスワード | 会員専用操作が可能なログイン状態未作成 |
