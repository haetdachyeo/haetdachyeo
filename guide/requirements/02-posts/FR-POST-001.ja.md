# `FR-POST-001` ポスト作成

[한국어](FR-POST-001.md) | [English](FR-POST-001.en.md) | [日本語](FR-POST-001.ja.md)

← 戻る: [ポスト要件](../02-posts.ja.md)

| 項目 | 値 |
| --- | --- |
| 入力 | タイトル、本文 |
| 出力・状態 | 現在の会員が作成者の新規ポストを正確に1個作成、即時公開、当初の作成日時を保持 |
| 検証 | 共通ポスト規則を満たす |
| 権限 | ログインした会員のみ許可 |
| 失敗・拒否 | 入力無効・未ログイン時は未作成 |

| AC ID | 条件 | 期待結果 |
| --- | --- | --- |
| `AC-POST-001-01` | ログイン会員、有効なタイトル・本文 | 自分の公開ポストを正確に1個作成 |
| `AC-POST-001-02` | 両端の空白除去後にタイトルまたは本文が空 | ポスト未作成 |
| `AC-POST-001-03` | 両端の空白除去後、タイトルが正確に1個・255個、本文が正確に1個・100,000個のコードポイント / タイトル256個または本文100,001個 | 前者は作成可能 / 後者は作成不可 |
| `AC-POST-001-04` | 未ログイン訪問者、有効なタイトル・本文 | ポスト未作成 |
