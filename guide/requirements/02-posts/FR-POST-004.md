# `FR-POST-004` 포스트 수정

[한국어](FR-POST-004.md) | [English](FR-POST-004.en.md) | [日本語](FR-POST-004.ja.md)

← 돌아가기: [포스트 요구사항](../02-posts.md)

| 항목 | 값 |
| --- | --- |
| 입력 | 수정할 기존 공개 포스트 식별 정보, 새 제목, 새 본문 |
| 출력·상태 | 제목·본문 변경, 공개 조회에 반영, 원래 생성 시각 유지 |
| 검증 | 새 제목·본문이 공통 포스트 규칙 충족, 대상은 현재 존재하는 공개 포스트 |
| 권한 | 로그인한 작성자 본인만 허용 |
| 실패·거부 | 입력 무효 시 기존 제목·본문 유지. 비로그인·비작성자 또는 영구 삭제되어 존재하지 않는 대상은 수정 불가 |

| AC ID | 조건 | 기대 결과 |
| --- | --- | --- |
| `AC-POST-004-01` | 작성자가 자신의 공개 포스트에 유효한 제목·본문 입력 | 수정 가능, 공개 목록·상세에 변경 반영 |
| `AC-POST-004-02` | 제목 또는 본문 무효 | 기존 제목·본문 유지 |
| `AC-POST-004-03` | 비로그인 방문자 또는 비작성자 회원 | 수정 불가 |
| `AC-POST-004-04` | 영구 삭제된 포스트, 작성자의 수정 시도 포함 | 수정 불가 |
