# `FR-POST-001` 포스트 작성

| 항목 | 값 |
| --- | --- |
| 입력 | 제목, 본문 |
| 출력·상태 | 현재 회원이 작성자인 새 포스트 정확히 1개, 즉시 공개, 원래 생성 시각 보유 |
| 검증 | 공통 포스트 규칙 충족 |
| 권한 | 로그인한 회원만 허용 |
| 실패·거부 | 입력 무효·비로그인 시 미생성 |

| AC ID | 조건 | 기대 결과 |
| --- | --- | --- |
| `AC-POST-001-01` | 로그인 회원, 유효한 제목·본문 | 자신의 공개 포스트 정확히 1개 생성 |
| `AC-POST-001-02` | 양 끝 공백 제거 후 제목 또는 본문이 빈 값 | 포스트 미생성 |
| `AC-POST-001-03` | 양 끝 공백 제거 후 제목 정확히 1개·255개, 본문 정확히 1개·100,000개 코드 포인트 / 제목 256개 또는 본문 100,001개 | 전자는 생성 가능 / 후자는 생성 불가 |
| `AC-POST-001-04` | 비로그인 방문자, 유효한 제목·본문 | 포스트 미생성 |
