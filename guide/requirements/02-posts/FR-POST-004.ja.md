# `FR-POST-004` ポスト変更

[한국어](FR-POST-004.md) | [English](FR-POST-004.en.md) | [日本語](FR-POST-004.ja.md)

← 戻る: [ポスト要件](../02-posts.ja.md)

| 項目 | 値 |
| --- | --- |
| 入力 | 変更する既存公開ポストの識別情報、新しいタイトル、新しい本文 |
| 出力・状態 | タイトル・本文を変更、公開閲覧に反映、当初の作成日時を維持 |
| 検証 | 新しいタイトル・本文が共通ポスト規則を満たす、対象は現在存在する公開ポスト |
| 権限 | ログインした作成者本人のみ許可 |
| 失敗・拒否 | 入力無効時は既存タイトル・本文を維持。未ログイン・非作成者、または完全削除されて存在しない対象は変更不可 |

| AC ID | 条件 | 期待結果 |
| --- | --- | --- |
| `AC-POST-004-01` | 作成者が自分の公開ポストに有効なタイトル・本文を入力 | 変更可能、公開一覧・詳細に変更を反映 |
| `AC-POST-004-02` | タイトルまたは本文が無効 | 既存タイトル・本文を維持 |
| `AC-POST-004-03` | 未ログイン訪問者または非作成者の会員 | 変更不可 |
| `AC-POST-004-04` | 完全削除されたポスト、作成者の変更試行を含む | 変更不可 |
