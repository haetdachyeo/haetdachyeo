# `FR-POST-005` ポスト削除

[한국어](FR-POST-005.md) | [English](FR-POST-005.en.md) | [日本語](FR-POST-005.ja.md)

← 戻る: [ポスト要件](../02-posts.ja.md)

| 項目 | 値 |
| --- | --- |
| 入力 | 削除する既存公開ポストの識別情報 |
| 出力・状態 | ポストを完全削除し、以後は誰も閲覧・変更・復元・再削除できない |
| 検証 | 現在存在する公開ポストのみ対象 |
| 権限 | ログインした作成者が所有する既存公開ポストのみ許可 |
| 失敗・拒否 | 未ログイン・非作成者による権限のない試行、および利用できない対象への試行は状態を変更しない。エラー表現はStage 08で定義 |

| AC ID | 条件 | 期待結果 |
| --- | --- | --- |
| `AC-POST-005-01` | ログインした作成者が所有する既存公開ポストを削除 | 完全削除されて公開一覧・詳細から除外され、以後は閲覧・変更・復元・再削除不可 |
| `AC-POST-005-02` | 未ログイン訪問者または非作成者の会員による削除試行 | 削除不可、対象の内容・公開可用性・所有権は不変 |
| `AC-POST-005-03` | 完全削除されて存在しないポストへの再削除試行 | 再削除不可、状態変更なし |
