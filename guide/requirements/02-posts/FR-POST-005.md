# `FR-POST-005` 포스트 삭제

[한국어](FR-POST-005.md) | [English](FR-POST-005.en.md) | [日本語](FR-POST-005.ja.md)

← 돌아가기: [포스트 요구사항](../02-posts.md)

| 항목 | 값 |
| --- | --- |
| 입력 | 삭제할 기존 공개 포스트 식별 정보 |
| 출력·상태 | 포스트를 영구 삭제하여 이후 누구도 조회·수정·복원·재삭제할 수 없음 |
| 검증 | 현재 존재하는 공개 포스트만 대상 |
| 권한 | 로그인한 작성자가 소유한 기존 공개 포스트만 허용 |
| 실패·거부 | 비로그인·비작성자의 무권한 시도와 존재하지 않는 대상에 대한 시도는 상태를 변경하지 않음. 오류 표현은 Stage 08에서 정의 |

| AC ID | 조건 | 기대 결과 |
| --- | --- | --- |
| `AC-POST-005-01` | 로그인한 작성자가 자신이 소유한 기존 공개 포스트 삭제 | 영구 삭제되어 공개 목록·상세에서 제외되고 이후 조회·수정·복원·재삭제 불가 |
| `AC-POST-005-02` | 비로그인 방문자 또는 비작성자 회원의 삭제 시도 | 삭제 불가, 대상 내용·공개 가용성·소유권 불변 |
| `AC-POST-005-03` | 영구 삭제되어 존재하지 않는 포스트의 재삭제 시도 | 재삭제 불가, 상태 변경 없음 |
