# `FR-POST-002` 公開ポスト一覧閲覧

[한국어](FR-POST-002.md) | [English](FR-POST-002.en.md) | [日本語](FR-POST-002.ja.md)

← 戻る: [ポスト要件](../02-posts.ja.md)

| 項目 | 値 |
| --- | --- |
| 入力 | 公開一覧の最初または後続結果の閲覧 |
| 出力・状態 | 現在存在する公開ポストのみを含む |
| 検証 | 結果ごとに最大20件、当初の作成日時の降順、20件超過時はすべての公開ポストを後続結果で漏れなく閲覧可能 |
| 権限 | 訪問者・ログイン会員ともに許可、同じ公開範囲 |
| 失敗・拒否 | 完全削除されたポストはすべての公開一覧結果に存在しない |

| AC ID | 条件 | 期待結果 |
| --- | --- | --- |
| `AC-POST-002-01` | 公開ポストの当初の作成日時が相互に異なる | 最新の当初の作成日時から降順 |
| `AC-POST-002-02` | 公開ポスト21件以上 | 結果ごとに20件以下、最初の結果にないポストも後続結果で閲覧可能 |
| `AC-POST-002-03` | 訪問者またはログイン会員 | 同一の公開範囲を適用 |
| `AC-POST-002-04` | 公開ポストを完全削除 | 削除直後からすべての公開一覧結果に存在しない |
