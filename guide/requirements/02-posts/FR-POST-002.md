# `FR-POST-002` 공개 포스트 목록 조회

[한국어](FR-POST-002.md) | [English](FR-POST-002.en.md) | [日本語](FR-POST-002.ja.md)

← 돌아가기: [포스트 요구사항](../02-posts.md)

| 항목 | 값 |
| --- | --- |
| 입력 | 공개 목록 최초 또는 후속 결과 조회 |
| 출력·상태 | 현재 존재하는 공개 포스트만 포함 |
| 검증 | 결과당 최대 20개, 원래 생성 시각 내림차순, 20개 초과 시 모든 공개 포스트를 후속 결과로 빠짐없이 조회 가능 |
| 권한 | 방문자·로그인 회원 모두 허용, 같은 공개 범위 |
| 실패·거부 | 영구 삭제된 포스트는 모든 공개 목록 결과에 존재하지 않음 |

| AC ID | 조건 | 기대 결과 |
| --- | --- | --- |
| `AC-POST-002-01` | 공개 포스트의 원래 생성 시각이 서로 다름 | 최신 원래 생성 시각부터 내림차순 |
| `AC-POST-002-02` | 공개 포스트 21개 이상 | 결과당 20개 이하, 첫 결과 미포함 포스트도 후속 결과로 조회 가능 |
| `AC-POST-002-03` | 방문자 또는 로그인 회원 | 동일한 공개 범위 적용 |
| `AC-POST-002-04` | 공개 포스트 영구 삭제 | 삭제 직후부터 모든 공개 목록 결과에 존재하지 않음 |
