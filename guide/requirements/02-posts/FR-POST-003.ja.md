| 項目 | 値 |
| --- | --- |
| 入力 | 特定ポストの識別情報 |
| 出力・状態 | 現在存在する公開ポストのタイトル・本文を含む詳細内容 |
| 検証 | 現在存在する公開ポストのみ対象 |
| 権限 | 訪問者・ログイン会員ともに許可 |

| AC ID | 条件 | 期待結果 |
| --- | --- | --- |

| `AC-POST-003-02` | 公開ポストを完全削除 | 削除直後から作成者を含む誰も詳細を閲覧不可 |
