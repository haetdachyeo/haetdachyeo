# `NFR-AVAIL-001` 初回リリース機能の月間可用性

[한국어](NFR-AVAIL-001.md) | [English](NFR-AVAIL-001.en.md) | [日本語](NFR-AVAIL-001.ja.md)

← 戻る: [品質要件](../04-quality.ja.md)

| 項目 | 値 |
| --- | --- |
| 入力・対象 | 会員登録、ログイン、ログアウト、ポスト作成、公開一覧閲覧、公開詳細閲覧、変更、完全削除 |
| 出力・基準 | 対象操作別の月間可用性99.5%以上 |
| 可用定義 | 有効かつ権限のある要求に本文書の製品レベルの結果を提供可能 |
| 非可用定義 | 対象操作のいずれか一つでも定義済みの製品レベルの結果を提供できない時間は当該操作の非可用時間 |
| 検証 | 一か月間の対象操作別の可用時間 / 全測定時間を測定 |
| 権限 | 各機能要件の権限を適用 |
| 失敗・拒否 | 対象操作別の月間可用性が99.5%未満の場合は要件未達 |

| AC ID | 条件 | 期待結果 |
| --- | --- | --- |
| `AC-AVAIL-001-01` | 一か月、対象操作別に測定 | 可用時間 / 全測定時間99.5%以上 |
