# 프로젝트 범위

## 포함 범위

프로젝트의 목적을 달성하기 위해 제공할 기능을 작성한다. 기능별로 누가 무엇을 할 수 있는지 알 수 있도록 적는다.

- 어떤 기능을 제공하는가?
- 각 기능은 어떤 사용자가 이용할 수 있는가?
- 목적을 달성하는 데 필요한 기능이 빠지지 않았는가?

## 제외 범위

프로젝트와 관련이 있거나 포함된 것으로 오해하기 쉽지만, 현재 설계와 구현에는 포함하지 않을 기능을 작성한다. 제외한 기능을 향후 제공하기로 약속하는 것은 아니다.

- 어떤 기능을 제공하지 않는가?
- 포함 범위와 혼동하기 쉬운 기능 중 명시적으로 제외해야 할 것은 무엇인가?

## 제공 범위의 경계

기능 이름만으로는 해석이 갈릴 수 있는 제공 범위를 작성한다. 포함한 기능이 어디까지 동작하고 어디부터는 제공하지 않는지 정한다.

- 기능을 어디까지 제공하는가?
- 사용자 역할에 따라 이용할 수 있는 범위가 다른가?
- 공개 여부, 복구 가능 여부처럼 범위에 영향을 주는 조건은 무엇인가?

입력값의 상세 검증 규칙과 처리 순서는 요구사항과 사용자 흐름을 정할 때 구체화한다. 여기서는 포함 여부와 기능의 큰 경계를 판단할 수 있는 수준으로 작성한다.
