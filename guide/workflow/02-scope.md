# 블로그 서비스의 범위

## 포함 범위

첫 배포 필수 기능.

| 기능 | 사용자 | 제공 내용 |
| --- | --- | --- |
| 회원가입 | 비로그인 방문자 | 이메일·비밀번호로 계정 생성 |
| 로그인 | 비로그인 방문자 | 가입 계정으로 로그인 |
| 로그아웃 | 로그인 회원 | 현재 이용 상태의 로그인 종료 |
| 글 작성 | 로그인 회원 | 제목·본문으로 본인 글 작성 |
| 공개 목록 | 회원·방문자 | 공개 글 목록 조회 |
| 공개 상세 | 회원·방문자 | 공개 글 제목·본문 조회 |
| 글 수정 | 로그인 작성자 | 본인 글 제목·본문 수정 |
| 영구 삭제 | 로그인 작성자 | 본인 글 영구 삭제 |

## 제외 범위

현재 설계·구현에서 제외. 향후 제공 약속 없음.

- 댓글
- 좋아요
- 팔로우
- 검색
- 카테고리와 태그
- 이미지·동영상 등 미디어 업로드
- 초안 저장과 예약 발행
- 관리자 기능
- 소셜 로그인
- 비밀번호 복구
- 이메일 인증
- 계정 삭제

## 제공 범위의 경계

- **공개**: 작성 즉시 공개. 비공개 글 없음. 회원·비로그인 방문자의 조회 범위 동일.
- **권한**: 작성은 로그인 회원, 수정·삭제는 로그인 작성자만 허용. 타인 글 관리·소유권 이전 제외.
- **수정**: 제목·본문만 변경. 작성자·공개 상태·원래 생성 시각 유지.
- **삭제**: 삭제 직후 모든 목록·상세에서 제외. 작성자를 포함한 누구도 조회·수정·복원·재삭제 불가.
- **로그아웃**: 현재 이용 상태만 종료. 계정·글·다른 회원의 로그인 상태 유지.
- **외부 연동**: 외부 신원 제공자·시스템 연동 제외.

## 기능별 동작 규칙

기능별 동작·데이터의 기준. 공통 책임과 배치 원칙은 [내부 설계 방식](03-architecture/02-internal-design.md)에서 관리.

### 데이터 책임

- 계정·인증: 회원·세션·입출력 타입과 규칙 소유. 글 관리: 글·입출력 타입·입력·작성자 권한 규칙 소유.
- 글은 작성자 회원 식별자만 보관. 계정 저장소·세션을 직접 조회하거나 비밀번호·세션 정보를 복제하지 않음.
- 비밀번호 보호 구현은 비밀번호·저장 해시를 받아 생성·검증. 해시 형식·알고리즘은 구현에 한정. 평문 저장·로그 금지. 알고리즘·비용은 보안 상세 사양에서 확정.

### 인증과 세션

- 로그인: 계정 조회·비밀번호 검증 → 세션 저장 완료 → 식별자 반환·쿠키 응답. 가입 시 자동 로그인 추가 없음.
- 보호된 동작: 세션 확인 후 회원 식별자 전달. 본문의 회원 식별자는 신뢰하지 않으며, 무효 세션은 변경 호출 없이 거부. 공개 목록·상세는 세션 불필요.
- 로그아웃: 현재 세션 폐기 저장 → 쿠키 제거·성공 응답. 다른 세션·계정·글은 유지.

### 글 변경

- 입력·작성자 권한 확인 후 변경. 수정·삭제 저장 계약에 글·현재 회원 식별자 전달, 실제 변경 시 대상 존재·소유권 재확인.
- 성공 응답 후 시작한 조회에 변경 반영. 삭제 이후의 조회·수정·복원·재삭제 금지는 제공 범위의 경계와 동일.

### 저장과 오류

- 원자적 저장 단위: 회원 생성·세션 생성·현재 세션 폐기·글 작성/수정/삭제 각각. 원자성의 공통 보장 방식은 내부 설계 방식에 따름.
- 저장 오류: 중복·대상 없음·접근 거부·저장 실패로 분류. 입력·인증·권한·대상·처리 실패를 API 응답으로 변환. 오류 우선순위·상태 코드·제약 매핑은 후속 API·DB 사양에서 확정.

### 검증 조건과 후속 결정

- 요청 검증: 비로그인·타인의 글 변경 거부, 공개 조회 허용, 현재 세션만 로그아웃, 변경 성공 후 조회 반영.
- DB 검증: 원자성·중복·대상 없음·소유권 조건·오류 분류. 구현·기능·DB 통합 검증은 미실시.
- 미확정: 구체 인터페이스, 필드별 입력 검증·오류 우선순위·상태 코드, DB 스키마·제약/오류 매핑·동시 수정·격리 수준·중복 요청, 인증·보안 설정, 배포·운영·복원 후 삭제 보장. 담당 상세 사양에서 확정하고 관련 문서를 동기화.
