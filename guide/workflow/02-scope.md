# 블로그 서비스의 범위

## 포함 범위

첫 배포 필수 기능.

| 기능 | 사용자 | 제공 내용 |
| --- | --- | --- |
| 회원가입 | 비로그인 방문자 | 이메일·비밀번호로 계정 생성 |
| 로그인 | 비로그인 방문자 | 가입 계정으로 로그인 |
| 로그아웃 | 로그인 회원 | 현재 이용 상태의 로그인 종료 |
| 글 작성 | 로그인 회원 | 제목·본문으로 본인 글 작성 |
| 공개 목록 | 회원·방문자 | 공개 글 목록 조회 |
| 공개 상세 | 회원·방문자 | 공개 글 제목·본문 조회 |
| 글 수정 | 로그인 작성자 | 본인 글 제목·본문 수정 |
| 영구 삭제 | 로그인 작성자 | 본인 글 영구 삭제 |

## 제외 범위

현재 설계·구현에서 제외. 향후 제공 약속 없음.

- 댓글
- 좋아요
- 팔로우
- 검색
- 카테고리와 태그
- 이미지·동영상 등 미디어 업로드
- 초안 저장과 예약 발행
- 관리자 기능
- 소셜 로그인
- 비밀번호 복구
- 이메일 인증
- 계정 삭제

## 제공 범위의 경계

- **공개**: 작성 즉시 공개. 비공개 글 없음. 회원·비로그인 방문자의 조회 범위 동일.
- **권한**: 작성은 로그인 회원, 수정·삭제는 로그인 작성자만 허용. 타인 글 관리·소유권 이전 제외.
- **수정**: 제목·본문만 변경. 작성자·공개 상태·원래 생성 시각 유지.
- **삭제**: 삭제 직후 모든 목록·상세에서 제외. 작성자를 포함한 누구도 조회·수정·복원·재삭제 불가.
- **로그아웃**: 현재 이용 상태만 종료. 계정·글·다른 회원의 로그인 상태 유지.
- **외부 연동**: 외부 신원 제공자·시스템 연동 제외.
