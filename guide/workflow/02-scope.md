# 블로그 서비스의 범위

## 포함 범위

첫 번째 배포에서는 다음 기능을 모두 제공한다.

- **회원가입**: 비로그인 방문자가 이메일과 비밀번호로 계정을 만들 수 있다.
- **로그인**: 비로그인 방문자가 가입한 계정으로 로그인할 수 있다.
- **로그아웃**: 로그인한 회원이 현재 이용 상태에서 로그아웃할 수 있다.
- **글 작성**: 로그인한 회원이 제목과 본문으로 자신의 글을 작성할 수 있다.
- **공개 글 목록 조회**: 회원과 방문자가 공개된 글의 목록을 볼 수 있다.
- **공개 글 상세 조회**: 회원과 방문자가 공개된 글의 제목과 본문을 읽을 수 있다.
- **글 수정**: 로그인한 작성자가 자신의 글의 제목과 본문을 수정할 수 있다.
- **글 영구 삭제**: 로그인한 작성자가 자신의 글을 영구 삭제할 수 있다.

## 제외 범위

다음 기능은 현재 설계와 구현에 포함하지 않는다. 향후 제공을 약속하는 것은 아니다.

- 댓글
- 좋아요
- 팔로우
- 검색
- 카테고리와 태그
- 이미지·동영상 등 미디어 업로드
- 초안 저장과 예약 발행
- 관리자 기능
- 소셜 로그인
- 비밀번호 복구
- 이메일 인증
- 계정 삭제

## 제공 범위의 경계

- **공개 범위**: 작성한 글은 즉시 공개된다. 비공개 글은 제공하지 않으며, 회원과 비로그인 방문자는 같은 범위의 공개 글을 읽을 수 있다.
- **작성·관리 권한**: 글 작성은 로그인한 회원에게만 허용한다. 기존 글의 수정과 삭제는 로그인한 작성자 본인에게만 허용하며, 다른 회원의 글을 관리하거나 소유권을 이전하는 기능은 제공하지 않는다.
- **수정 범위**: 글의 제목과 본문을 수정할 수 있다. 수정해도 작성자, 공개 상태, 원래 생성 시각은 유지한다.
- **삭제 범위**: 삭제는 영구적이다. 삭제 직후부터 모든 공개 목록과 상세 조회에서 제외되며, 작성자를 포함한 누구도 해당 글을 조회·수정·복원·재삭제할 수 없다.
- **로그아웃 범위**: 현재 이용 상태의 로그인을 종료한다. 계정이나 글은 삭제하지 않고 다른 회원의 로그인 상태도 변경하지 않는다.
- **외부 연동 범위**: 외부 신원 제공자나 외부 시스템과의 연동은 포함하지 않는다.
