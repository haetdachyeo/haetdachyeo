# 기술과 아키텍처

## 설계 방향

목적·범위·예상 규모에 맞는 설계 방향 요약.

- 선택한 구조·적합한 이유
- 주요 제약: 예산·환경·팀 역량·성능·보안

제약조건·판단 근거의 상세 정의는 담당 문서에 작성.

## 시스템 구성 요약

- 주요 구성요소·역할·연결 관계
- 필요 시 간단한 구성도

상세 설계: 내부 모듈 책임·의존 관계, 통신·데이터 흐름·장애 경계.

## 사용 기술 요약

- 언어·프레임워크·저장소·실행 환경
- 기술별 용도·적용 범위·버전

상세 설계: 선택 이유·대안·트레이드오프·적용 방식.

## 상세 설계 문서 안내

- 위치: 대표 문서와 같은 위치의 `03-architecture/`.
- 분리 기준: 필요한 설계 영역·독립 주제. 예: 제약조건·기술 선택·시스템 구성·모듈 경계.
- 안내 항목: 실제 작성한 문서 경로·담당 주제·읽는 순서.
- 상세 문서 내용: 조건·규칙·선택·이유·대안·트레이드오프·검증 방법.
- 사양의 기준: 항목별 담당 상세 문서 한곳.
- 대표 문서 역할: 요약·안내. 상세 변경 시 관련 요약 동기화.
