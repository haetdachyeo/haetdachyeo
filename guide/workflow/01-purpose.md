# 블로그 서비스의 목적과 설명

## 목적

회원의 글 작성·관리와 회원·방문자의 공개 글 조회를 제공하는 기본 블로그 서비스.

## 배경과 문제

- 필요: 작성자의 글 관리, 다른 사용자의 공개 글 조회.
- `미정`: 기존 사용 방식·한계, 서비스 제작의 구체적 계기.

## 대상 사용자

- **회원**: 자신의 글 작성·공개·수정·영구 삭제.
- **방문자**: 가입·로그인 없이 공개 글 목록·상세 조회. 로그인 회원도 같은 공개 범위 이용.

## 예상 사용 규모

아키텍처·코드 구성의 설계 전제.

| 항목 | 예상 |
| --- | --- |
| 시점 | 첫 배포 후 3개월 |
| 전체 사용자 | 회원·방문자 합계 1,000명 |
| 동시 사용자 | 50명 |

## 사용자에게 주는 가치

- **회원**: 한곳에서 글 작성·관리·공개, 본인만 수정·삭제.
- **방문자**: 계정 생성·로그인 없이 공개 글 열람.

기존 방식 대비 개선 효과: 배경·문제 구체화 후 보완. 현재 효과 단정 없음.

## 성공 기준

첫 배포 기능 검증: 아래 조건 모두 충족.

1. 회원가입·로그인·로그아웃 가능.
2. 로그인 회원의 글 작성 즉시 공개, 목록·상세 조회 가능.
3. 회원·비로그인 방문자의 공개 조회 범위 동일.
4. 작성자의 글 수정 결과를 공개 조회에 반영.
5. 영구 삭제 후 누구도 조회·복원 불가.
6. 비로그인 사용자의 작성·수정·삭제, 다른 회원의 수정·삭제 거부.

확인 방법: 회원·방문자 정상 이용, 비로그인·비작성자의 변경 시도 거부 검증.

품질 대상: 회원가입·로그인·로그아웃·글 작성·공개 목록·공개 상세·수정·영구 삭제, 총 8개 동작.
