# ブログサービスの目的と説明

## 目的

会員の記事作成・管理と、会員・訪問者の公開記事閲覧を提供する基本的なブログサービス。

## 背景と課題

- 必要な機能：作成者の記事管理、ほかのユーザーの公開記事閲覧。
- `未定`：従来の利用方法・限界、サービスを作る具体的なきっかけ。

## 対象ユーザー

- **会員**：自分の記事の作成・公開・編集・完全削除。
- **訪問者**：登録・ログインなしで公開記事の一覧・詳細を閲覧。ログイン会員も同じ公開範囲を利用。

## 想定利用規模

アーキテクチャ・コード構成の設計前提。

| 項目 | 想定 |
| --- | --- |
| 時点 | 初回リリースから3か月後 |
| 総ユーザー数 | 会員・訪問者合計1,000人 |
| 同時ユーザー数 | 50人 |

## ユーザーに提供する価値

- **会員**：一か所で記事を作成・管理・公開。編集・削除は本人のみ。
- **訪問者**：アカウント作成・ログインなしで公開記事を閲覧。

従来の方法に対する改善効果：背景・課題の具体化後に補足。現時点で効果の断定なし。

## 成功基準

初回リリースの機能検証：以下の条件をすべて満たすこと。

1. 会員登録・ログイン・ログアウトが可能。
2. ログイン会員の記事作成直後に公開、一覧・詳細で閲覧可能。
3. 会員・未ログイン訪問者の公開閲覧範囲が同一。
4. 作成者の編集結果を公開記事の閲覧に反映。
5. 完全削除後は誰も閲覧・復元不可。
6. 未ログインユーザーの作成・編集・削除、ほかの会員の編集・削除を拒否。

確認方法：会員・訪問者の通常利用、未ログインユーザー・作成者以外の変更拒否を検証。

品質基準の対象：会員登録・ログイン・ログアウト・記事作成・公開一覧・公開詳細・編集・完全削除の計8操作。

| 項目 | 基準 |
| --- | --- |
| 応答時間 | 同時ユーザー100人、操作別の成功リクエストのp95完了時間2秒以下 |
| 測定区間 | サービスのリクエスト受信から結果を利用可能になる時点まで |
| 測定対象外 | クライアント側のネットワーク転送・描画・ユーザーの思考時間 |
| 月間可用性 | 操作別99.5%以上。1か月間、有効かつ権限のあるリクエストに正常結果を提供できる時間 / 総測定時間 |
| 正常な拒否 | 無効・権限のないリクエストの正常な拒否は利用不能時間から除外 |

測定環境・同時ユーザー100人の操作構成・負荷の算定根拠：設計で確定。
ユーザー価値の達成指標・判定時点：`未定`。機能・品質の達成だけでは価値の検証を代替しない。
