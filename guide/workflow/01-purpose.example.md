# 프로젝트 목적과 설명

## 목적

첫 문장에 만들 대상·달성 목표 명시. 배경보다 결론 우선.

## 배경과 문제

- 사용자의 현재 문제
- 기존 해결 방식·한계
- 프로젝트가 필요한 이유

## 대상 사용자

- 주요 사용자·유형별 구분
- 사용 상황·필요

## 예상 사용 규모

작성자가 정하는 아키텍처·코드 구성의 설계 전제.

- 예상 시점
- 전체 사용자 수
- 동시 사용자 수

## 사용자에게 주는 가치

기능 나열보다 사용자 변화 중심.

- 기존 방식 대비 개선점
- 줄어드는 불편·부담

## 성공 기준

- 목적·사용자 가치 달성 기준
- 기준별 확인 방법·판단 시점
