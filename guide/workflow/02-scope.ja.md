# ブログサービスの範囲

## 対象範囲

初回リリースの必須機能。

| 機能 | ユーザー | 提供内容 |
| --- | --- | --- |
| 会員登録 | 未ログイン訪問者 | メールアドレス・パスワードでアカウント作成 |
| ログイン | 未ログイン訪問者 | 登録済みアカウントでログイン |
| ログアウト | ログイン会員 | 現在の利用状態のログイン終了 |
| 記事作成 | ログイン会員 | タイトル・本文で自分の記事を作成 |
| 公開一覧 | 会員・訪問者 | 公開記事の一覧閲覧 |
| 公開詳細 | 会員・訪問者 | 公開記事のタイトル・本文閲覧 |
| 記事編集 | ログイン中の作成者 | 自分の記事のタイトル・本文を編集 |
| 完全削除 | ログイン中の作成者 | 自分の記事を完全削除 |

## 対象外

現在の設計・実装から除外。将来の提供の約束なし。

- コメント
- いいね
- フォロー
- 検索
- カテゴリとタグ
- 画像・動画などのメディアアップロード
- 下書き保存と予約投稿
- 管理者機能
- ソーシャルログイン
- パスワードの復旧
- メールアドレス認証
- アカウント削除

## 提供範囲の境界

- **公開**：作成直後に公開。非公開記事なし。会員・未ログイン訪問者の閲覧範囲は同一。
- **権限**：作成はログイン会員、編集・削除はログイン中の作成者のみ。他人の記事の管理・所有権移転は対象外。
- **編集**：タイトル・本文のみ変更。作成者・公開状態・元の作成時刻を維持。
- **削除**：削除直後に全一覧・詳細から除外。作成者を含む誰も閲覧・編集・復元・再削除不可。
- **ログアウト**：現在の利用状態のみ終了。アカウント・記事・ほかの会員のログイン状態は維持。
- **外部連携**：外部認証プロバイダー・外部システムとの連携は対象外。

## 機能別の動作ルール

機能別の動作・データの基準。共通の責務・配置原則は[内部設計](03-architecture/02-internal-design.ja.md)で管理。

### データの責務

- アカウント・認証は会員・セッション・入出力の型とルールを所有。記事管理は記事・入出力の型、入力・作成者権限のルールを所有。
- 記事は作成者の会員識別子だけを保持。アカウントの保存処理・セッションの直接照会、パスワード・セッション情報の複製は禁止。
- パスワード保護実装はパスワード・保存済みハッシュを受け取り、生成・検証。ハッシュ形式・アルゴリズムは実装に限定。平文保存・ログは禁止。アルゴリズム・コストはセキュリティの詳細仕様で確定。

### 認証とセッション

- ログイン：アカウント照会・パスワード検証 → セッション保存完了 → 識別子返却・Cookieレスポンス。登録時の自動ログインは追加しない。
- 保護対象の操作：セッション確認後に会員識別子を渡す。本文の会員識別子は信頼せず、無効セッションは変更を呼び出さず拒否。公開一覧・詳細はセッション不要。
- ログアウト：現在のセッションの無効化を保存 → Cookie削除・成功レスポンス。他のセッション・アカウント・記事は維持。

### 記事の変更

- 入力・作成者権限の確認後に変更。編集・削除の保存契約に記事・現在の会員識別子を渡し、実際の変更時に対象の存在・所有権を再確認。
- 成功レスポンス後に開始した取得に変更を反映。削除後の閲覧・編集・復元・再削除の禁止は、提供範囲の境界と同じ。

### 保存とエラー

- 原子的な保存単位：会員作成・セッション作成・現在のセッションの無効化・記事作成/編集/削除のそれぞれ。共通の原子性保証方式は内部設計に従う。
- 保存エラー：重複・対象なし・アクセス拒否・保存失敗に分類。入力・認証・権限・対象・処理の失敗をAPIレスポンスに変換。エラー優先順位・ステータスコード・制約との対応は後続のAPI・DB仕様で確定。

### 検証条件と後続の決定

- リクエスト検証：未ログイン・他人の記事変更の拒否、公開閲覧の許可、現在のセッションだけのログアウト、変更成功後の取得への反映。
- DB検証：原子性・重複・対象なし・所有権条件・エラー分類。実装・機能・DB統合の検証は未実施。
- 未確定：具体的なインターフェース、項目別入力検証・エラー優先順位・ステータスコード、DBスキーマ・制約/エラー対応・同時編集・分離レベル・重複リクエスト、認証・セキュリティ設定、デプロイ・運用・復元後の削除保証。担当の詳細仕様で確定し、関連文書を同期。
